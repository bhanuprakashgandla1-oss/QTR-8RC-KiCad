# QTR-8RC KiCad Library

An unofficial KiCad symbol and connector footprint for the Pololu QTR-8RC reflectance sensor array.

## Contents
- QTR8RC.kicad_sym — schematic symbol
- QTR8RC.pretty/ — 1x11, 2.54 mm connector footprint

## Installation
1. Add QTR8RC.kicad_sym through Preferences > Manage Symbol Libraries.
2. Add QTR8RC.pretty through Preferences > Manage Footprint Libraries.

## Reference
https://www.pololu.com/product/961

## Important
This is an unofficial library and is not affiliated with or endorsed by Pololu.
The footprint represents a connector, not the complete sensor board.
Verify the connector pin order, numbering, and physical dimensions against the actual module before manufacturing.

The initial pin mapping has not been independently verified.
